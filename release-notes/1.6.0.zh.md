BaoCode Codex：codex 那个产品，独立的一版

这是另一个程序：和 BaoCode Claude 同一份源码，但它是**自己的一个产品**。自己的安装包、
自己的文件夹、自己的更新通道、自己的链接——装它不会动 Claude Code 那个，两个可以并排跑，
互相看不到对方的数据。

**它自带 Codex CLI**。OpenAI 的 CLI 就在安装包里（钉了版本，并按 registry 的校验值核对），
所以机器上没有 Codex 也不用装、不用下：应用直接跑包里那份。你自己有——在 PATH 上、
npm 装的、或者 Codex 桌面版带的——就用你的，带你的登录和设置。

新功能
- 应用自带 Codex CLI（0.164.0）：第一次对话之前不用装、不用等下载。
- 各方面都是自己的产品：自己的安装包与卸载项、自己的数据目录
  （`%APPDATA%\baocode-codex`）、自己的窗口与注册信息、自己的链接
  （`baocode-codex://`）、自己的 Stash 目录、自己的钥匙串条目，以及自己的远端服务器构建。
- 计划模式：agent 只读地做计划，点「开始构建」才照着做。

修好了
- 适配层现在按 app-server 的真实协议说话。有三个缺陷会让机器**根本起不来**：
  发了服务器没有的参数（可能整个请求被拒）、发了一个并不存在的协作模式、
  以及请求 id 会和服务器的数字撞上——撞上时那一轮就永远等不到回音。
- 服务器报的东西都用上了：思考的正文、MCP 服务器状态、配额推送；
  用户拒绝的命令不再一直显示成「在运行」。
- Stash 技能写进这个产品**自己的** agent 目录，不再写进 Claude Code 的。
