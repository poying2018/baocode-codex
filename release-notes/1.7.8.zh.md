BaoCode Codex 1.7.8：自定义上游的两个尾巴

1.7.6/1.7.7 的日志揭出又两个问题（正是那两行 Missing environment variable 与
Model metadata not found）：

修复
- **上游密钥从未送到进程**：它被放进了启动参数里的环境变量表，却没有并进
  子进程的环境——现在并入了，`Missing environment variable` 消失。
- **回合用错模型名**：发给服务器的模型名是应用里的引用（@provider/qoder-cn/dfmodel），
  而服务器只认自己伺服的短名（dfmodel）。现在按上游伺服的名字询问，
  `Model metadata not found` 消失。
- 测试：mock 记录每回合询问的模型名，断言是上游的短名。
