BaoCode Codex 1.7.13: the proxy learns to speak Responses

The stderr of 1.7.12 exposed it: Codex 0.166 dropped wire_api=chat
outright (its own discussion 7782), and the server died at start. The
only way through was for the proxy to speak Responses itself.

Fixed
- The upstream server's wire is responses again, as it must be.
- The proxy has a Responses endpoint now: the server's request is turned
  into the shape the upstream speaks (through the same translators the
  Claude side uses), and the upstream's events back into the Responses
  events the server reads - the items, the text deltas, the function
  calls with their arguments, and the completed event with the usage.
- Both directions are tested; a stream that ends without saying so is
  finished whole.
