BaoCode Codex 1.7.2: the installation goes where it can

This closes the installer's last gap. The previous release made the Start
Menu folder and Software\Classes skips instead of aborts; the browsers'
registration keys — Chrome, Edge and Chromium's native-messaging hosts — were
left out. A profile that refuses those rolled the whole installation back at
`Software\Google`, after the program itself had already gone in.

Fixed
- The browsers' keys are guarded the same way: what the machine refuses is
  skipped (the app speaks for its browser extension when it runs), and the
  program files are never taken back. Every write outside the program's own
  folder is guarded now.
- The Codex CLI the bundle carries follows the registry at **0.166.0**
  (bumped by the daily workflow).
- The release pipeline runs the full test suite before building anything, so
  a broken commit does not become a release.
