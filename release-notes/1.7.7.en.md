BaoCode Codex 1.7.7: your own upstream, actually fixed

The stderr log of 1.7.6 exposed the truth: `error: unexpected argument
'--model' found`. The server for one of your own upstreams never started
at all - the `--model` it was given is not an argument the app-server
accepts.

Fixed
- The model rides as `--config model=...`, which the server reads; a
  server for your upstream now starts with your model for the first time.
- Proven by the test that runs a real app-server through a whole turn.
- Should anything still fail, codex-stderr.log and the error say what
  Codex itself said.
