BaoCode Codex 1.7.9: changing the model mid-conversation really works

In 1.7.8 the model in effect was resolved from the server the last turn
ran on, whose own model was fixed when it started - so a change of pick
mid-conversation kept asking for the old name. That was "cannot change
the model mid-conversation".

Fixed
- The model in effect is resolved from the pick of the moment: the next
  turn after a change (including one already queued) asks for the new
  model.
- Tested: the mock records the model each turn asks for, and the test
  asserts the new name after a mid-conversation change.
