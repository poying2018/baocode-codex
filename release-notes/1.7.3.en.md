BaoCode Codex 1.7.3: the browser extension, one chain

This release puts the browser extension's "get it" chain together: the address
the app's button opens, the extension's manifest and its download all point at
this repository's own release now, and each of them has been fetched
anonymously to be sure it answers.

New
- A copy-installed app can be registered with Windows
  (tool/register_install.ps1): the browsers' hosts, the baocode-codex://
  scheme, the Explorer context menu, the Start Menu and the Control Panel's
  uninstall entry - a machine whose profile refused the installer's writes
  ends up just as installed after the script runs.

Fixed
- The app's "get the extension" address works: it pointed at a service this
  product does not run (a 404). The manifest, the download and the store's
  page come from this repository's releases, each fetched anonymously and
  verified.
- The extension's own pipeline publishes to the same release: the manifest
  after the zip it names, a tester's files carrying their tag, and no
  dependency on another product's download site.

For developers
- The browser bridge's end-to-end test runs on Windows: the host's path, the
  socket folder and the browser's temporary-directory variables follow the
  platform (BAO_BROWSER_HOST overrides the host's path).
